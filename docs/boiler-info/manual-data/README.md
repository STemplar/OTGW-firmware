# Handleidinggegevens bij actieve profielen

Volledige lijsten uit handleidingen (instellingen, meetwaarden, tellers, storingscodes) die
de handleiding niet aan OpenTherm koppelt. Ze horen bij een actief profiel in
`src/OTGW-firmware/data/`, maar staan niet op LittleFS: de UI gebruikt ze niet en de ketel
hoeft ze dus niet te versturen.

| Bestand | Hoort bij | Handleiding |
|---|---|---|
| `tzerra-ace-matic.json` | `data/tzerra-ace-matic.json` | 7875186-01 (20-06-2024) |

Codes die in de handleiding meer dan eens voorkomen (bijv. DP060, CP080), staan er ook
meer dan eens in, met paginanummer.
